# 15. Example files

[Start here](00-start-here.md)

These are small working examples you can inspect or adapt. They are demonstrations, not finished gameplay or graphics mods. In the launcher guide, use **Save example files as ZIP** above the page. On GitHub, the files are in this repository’s `examples` folder.

![Demo screenshot — open to enlarge](images/package-files.png)

[Open full-size image](images/package-files.png)

1. Save the ZIP somewhere you can find it, then extract it. Open `examples/mods`. Each subfolder is a separate example. Start with `hello-loader` for a mod that prints a message, or `configure-demo` for a settings form.

![Demo screenshot — open to enlarge](images/package-files.png)

[Open full-size image](images/package-files.png)

2. In a spare launcher setup, open Mods and choose Add Folder. Select ONE example’s folder, not the whole collection. It appears in the mod list, initially disabled. Read the matching chapter before enabling it. The packaging program for updates is in `examples/tools`.

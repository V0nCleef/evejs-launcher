# How to make a mod

Build an EveJS mod with launcher support, one feature at a time. This is the same illustrated guide available through **Mods → Make a mod** in the launcher.

Start with the overview, then choose the features your mod needs. The numbered files below follow the launcher’s sidebar order.

- [00. Start here](00-start-here.md)
- [01. Make your first package](01-first-mod.md)
- [02. Enable and restart](02-activation.md)
- [03. Add a Configure button](03-configure.md)
- [04. Choose form controls](04-controls.md)
- [05. Separate settings by profile](05-profiles.md)
- [06. Translate setting labels](06-languages.md)
- [07. Offer mod updates](07-mod-updates.md)
- [08. Add a helper when needed](08-helper-intro.md)
- [09. Remove and recover](09-removal.md)
- [10. Dependencies and load order](10-dependencies.md)
- [11. Integrate server source files](11-source-integration.md)
- [12. Support client file mods](12-client-files.md)
- [13. React to client start and exit](13-client-events.md)
- [14. Publish a mod update](14-publish-update.md)
- [15. Example files](15-example-files.md)

Each feature page explains what players see, includes screenshots, and puts code examples below a dividing line. The launcher version adds translations, text zoom, example-file export, and a **Hand off to your AI** button.

The [`reference`](reference/) folder contains the detailed technical contracts for developers and AI tools. You can follow the numbered guide without reading it.
